# Learning Tracker

## App Purpose
Learning Tracker is an iOS application designed to help users develop consistent learning habits and track their daily progress. Users can set learning goals, record their learning activities, and monitor their progress through a weekly calendar.

## Main Features
- **Set Learning Goals:** Choose a learning topic and select a timeframe (week, month, or year).
- **Daily Activity Tracking:** Log learning activities to track daily progress.
- **Freeze Days:** Freeze up to two days when users need a break.
- **Undo Actions:** Undo a learning or freeze action for the current day.
- **Weekly Progress:** View daily activity statuses throughout the week.
- **Activity Calendar:** Review previous monthly activity records.
- **Progress Statistics:** Track the number of learned and frozen days.

## Technologies Used
- Swift
- SwiftUI
- Xcode
- UserDefaults
